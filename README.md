## 🛠️ Tecnologías y Metodología
- Metodología: **Spec-Driven Development (SDD)**
- HTML5 Semántico + CSS3 (Variables, Responsive Mobile-First) + Vanilla JS
- Acciones rápidas de un toque (`mailto:` y `navigator.clipboard` con fallback)
- Diseñado para despliegue instantáneo en **Vercel** o cualquier CDN estático.
